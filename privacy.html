Privacy Policy

This application is used exclusively for personal access to my own Google Drive storage through rclone on Linux.

Google Drive Data

The application accesses Google Drive files only as directed by the account owner. Files may be downloaded, uploaded, modified or deleted.

Authentication

Authentication is performed using Google OAuth 2.0. OAuth credentials are stored locally in the user's rclone configuration.

Data Sharing

This integration does not operate a separate server or analytics service. Google Drive data is not intentionally shared with third parties by this integration.

Data Retention

Locally cached files and authentication credentials remain on the user's device until removed by the user or the application.

Access Revocation

Access can be revoked at any time through Google Account security settings.
